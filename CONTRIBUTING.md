# Contributing to LaViPoP

LaViPoP is an open-source software project developed and maintained by **TopLab – Toplak Laboratory e.U.**

## Contribution Policy

To preserve centralized development, copyright management, and future commercial licensing opportunities, LaViPoP does not currently accept external source code contributions or pull requests.

The official source code, release process, and development roadmap are maintained exclusively by TopLab.

Users are welcome to:

- Report bugs and technical issues.
- Suggest improvements and new features.
- Discuss possible commercial integrations.
- Fork, modify, and redistribute the software in accordance with the Apache License 2.0.

Please do not submit source code patches or other copyrightable material intended for incorporation into the official repository without prior written agreement.
