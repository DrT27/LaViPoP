# LaViPoP
LaViPoP (Language-aware Video Post-Processing) is an open-source Python tool for automated multilingual video production. It supports automatic language icons, animated watermarks, batch processing, customizable backgrounds, and portrait/landscape exports using FFmpeg and Dash.

## LaViPoP – Features & Roadmap
TopLab's Video Post Processor
### 1. Implemented Features
- Automated Video Post-Processing – Process videos through a Python-based workflow.
- Landscape & Portrait Export – Generate 16:9 landscape and 9:16 portrait videos from the same source.
- Automatic Background Adaptation – Choose between a static background image and a scaled, blurred version of the original video.
- Custom Watermark & Logo Integration – Add branding elements to videos.
- Animated Watermarks – Move watermarks between configurable positions over time.
- Flexible Watermark Positioning – Configure positions and offsets independently for different video formats.
- Logo & Language Icons – Include graphical overlays for branding and multilingual content.
- Interactive Web Dashboard – Configure video processing through a Python Dash interface.
- Video Preview – Preview layout and watermark positioning before processing.
- Batch Processing – Automatically generate multiple output formats.
- Progress Indication – Display processing status in the dashboard.
- Configurable Output Naming – Automatically assign suffixes such as _portrait and _landscape.
### 2. Planned Features
- Intro & Outro Integration – Automatically prepend and append branded video sequences.
- Audio Jingles – Add configurable intro/outro sounds or background music.
- Transitions & Effects – Introduce smooth fades and transitions between video segments.
- Audio Normalization – Automatically adjust audio levels for consistent playback.
- Text Overlays & Titles – Insert configurable titles, captions, and closing messages.
- Subtitles – Import or generate subtitles for multilingual publishing.
- Video Templates – Save and reuse configurations for different channels, projects, or customers.
- Advanced Batch Processing – Apply templates to entire directories of source videos.
- Platform-Specific Export Presets – Optimize exports for YouTube, YouTube Shorts, LinkedIn, Instagram, and TikTok.
- Command-Line Interface (CLI) – Enable scripted processing without the dashboard.
